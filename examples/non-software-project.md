# Non-software Project Example

Context:

- Linear is the formal ledger.
- There is no GitHub repository.
- Delivery evidence consists of documents, approvals, meeting records and measurable outcomes.

Example flow:

1. Meeting notes produce a candidate REQ and two Q items.
2. After owner confirmation, the REQ is written and related to analysis and collaboration tasks.
3. Deliverables are attached as accessible documents.
4. The audit checks source coverage, ownership, state consistency and evidence completeness.
5. It explicitly states that code verification was not applicable.
