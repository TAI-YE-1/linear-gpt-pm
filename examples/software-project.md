# Software Project Example

Context:

- Linear contains governance and delivery projects.
- GitHub contains the implementation repository.
- ChatGPT handles intake and reconciliation.
- Codex verifies PR, commit and test evidence and performs periodic audits.

Example flow:

1. A real customer report is analyzed as a candidate Q because the current version is unverified.
2. After reproduction, a PROB is confirmed.
3. Analysis, implementation and validation tasks are related to the PROB.
4. A PR and tests are linked as delivery evidence.
5. The audit checks that the Done task evidence matches the current commit.
6. Business acceptance remains a human decision.
